# 1
Step 1: Install Dependencies
To ensure Poetry installs directly into your existing ./venv rather than creating a separate cached virtual environment in ~/.cache/pypoetry, execute the following in your VS Code integrated terminal:

``` bash
# Tell poetry to prioritize the in-project .venv
poetry config virtualenvs.in-project true

# Install dependencies locked from pyproject.toml
poetry install
```

---

### Step 2: Verification of Package Imports

Run an inline check to verify modern LangGraph 1.0 HITL imports and FastAPI components resolve correctly:

```bash
poetry run python -c "from langgraph.types import interrupt, Command; from langgraph.checkpoint.memory import MemorySaver; import fastapi; print('Environment and imports verified successfully.')"

```

---

### Step 3: Run the FastAPI Server

Launch the orchestrator using Uvicorn:

```bash
poetry run uvicorn main:app --reload --port 8000

```
