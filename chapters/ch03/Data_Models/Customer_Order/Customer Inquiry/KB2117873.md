# How to view all invoices for a customer order.

Description :

How to view all invoices for a customer order.


**Resolution :**
There are a few ways to get this information:

Sales > Customer Order Entry.  Enter in the Customer Order ID.  Go to Info - Document Life Cycle.  This will display all invoices that have been generated against the Customer Order including Progress Billing invoices and Prepaid Accounts Receivable Invoices.

Sales > Customer Inquiry.   Enter in the Customer Order ID, browse and go to info - List Shipments and Invoices.  This will not include Progress Billing invoices.

Sales > Shipping Entry.  Enter in the Customer Order ID.  File - Print Packlist Report for the current order.  This will not include Progress Billing invoices.
