# KB0731699

## How to modify User Defined labels

Article Information
________________________________________________________________________________________________________________


Description :

How to modify User Defined labels 
 


Resolution :
User Defined Field Labels can be accessed from Customer Maintenance, Part Maintenance and Vendor Maintenance under Maintain, User Defined Field Labels.  Each module reads and writes to the same table in the database.  What is entered in one area is available throughout VISUAL and can be modified from any of the three modules above.

![
    

](image.png)

After selecting the User Defined Field Labels option under Maintain menu, the **Default** Label Set ID will always appear.  The **Default** set of labels can be changed, and new label sets can be defined by typing the name of the new label set over the **Default** name.

For example, a **Default* label set might be defined using Labels of TEST1, TEST2, TEST3, TEST4 and TEST5 for User Defined 1, 2, 3, 4 and 5.  Or, a new set of labels can be defined to be used, such as replacing **Default** with SIZING, and enter Length, Width, Height as labels to be used for this set as User Defined 1, 2 and 3 respectively.  After making the changes, save and exit the window.


After saving, when the user selects the User Defined Tab of a window, the different label sets will be available to select.  Each window will always default to the **Default** label set.  The user must choose the label set desired.  Once that label set is selected and the record saved, that label set will appear when the record is retrieved.

User Defined Fields can be used on any User Defined tab found, such as Work Order headers,  Customer Maintenance, Vendor Maintenance and Part Maintenance.  Each window would require the user to select the label set to be used.  Label sets are available in any program regardless of where the label set was defined or setup
