1.  Go to Admin > Costing Tools
Cost to check:  Shipments
Check the ‘Exceptions Only’ box
Click the ‘Run’ icon

When the rows return, go to Edit > Select All then Edit > Set Posting Candidate

2.  In SQL Server, run these scripts to turn on the posting candidates for all transactions related to the customer orders that are showing as exceptions:

UPDATE INVENTORY_TRANS SET POSTING_CANDIDATE = 'Y' WHERE CUST_ORDER_ID IN (SELECT ID FROM CUSTOMER_ORDER WHERE POSTING_CANDIDATE = 'Y')

UPDATE INVENTORY_TRANS SET POSTING_CANDIDATE = 'Y' WHERE TYPE = 'I' AND TRANSACTION_ID IN (SELECT IN_TRANS_ID FROM INV_TRANS_DIST WHERE
OUT_TRANS_ID IN (SELECT IT2.TRANSACTION_ID FROM INVENTORY_TRANS IT2 WHERE IT2.TYPE = 'O' AND IT2.POSTING_CANDIDATE = 'Y'))

UPDATE PURCHASE_ORDER SET POSTING_CANDIDATE = 'Y' WHERE ID IN (SELECT DISTINCT PURC_ORDER_ID FROM INVENTORY_TRANS WHERE POSTING_CANDIDATE = 'Y')

UPDATE PURC_ORDER_LINE SET POSTING_CANDIDATE = 'Y' WHERE PURC_ORDER_ID IN (SELECT DISTINCT PURC_ORDER_ID FROM INVENTORY_TRANS WHERE POSTING_CANDIDATE = 'Y') 

UPDATE CUSTOMER_ORDER SET POSTING_CANDIDATE = 'Y' WHERE ID IN (SELECT DISTINCT CUST_ORDER_ID FROM INVENTORY_TRANS WHERE POSTING_CANDIDATE = 'Y')

UPDATE WORK_ORDER SET POSTING_CANDIDATE = 'Y' WHERE TYPE = 'W' AND SUB_ID = '0' AND BASE_ID IN(SELECT DISTINCT WORKORDER_BASE_ID FROM
INVENTORY_TRANS WHERE POSTING_CANDIDATE = 'Y')

UPDATE INVENTORY_TRANS SET POSTING_CANDIDATE = 'N' WHERE CLASS != 'A' AND POSTING_CANDIDATE = 'Y'

3.  Run a full costing and post.  Follow step 1 again to verify the exceptions cleared.
