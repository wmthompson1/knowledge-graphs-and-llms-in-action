## WIP Balance Report
The WIP Balance Report shows workorders that have a balance in WIP at the end of the period the report is generated for.  Example:  A workorder is created in December.  Material is issued; labor tickets are entered.  Workorder is received in January and closed.  The WIP Balance Report for December will show the workorder as there is a balance in WIP.  The WIP Balance Report for January will not show the workorder as there is no balance in WIP.

## Workorders appearing erroneously
If workorders appear on the report erroneously, pull the workorder into the Manufacturing Window to verify the status is accurate.  Go to Info > Customer Order Status and review 'Total Production Ordered' and 'Total Production Received'.
Work order status should be....
Closed:  If fully received
Cancelled:  If there are no receipts and there are no expected receipts

If it is necessary to change the workorder status, run a full costing and post the journals after the change.

After a full costing and post, if the workorder remains on the WIP Balance Report:
Admin > Costing Tools > Options > Recalculate WIP Balances
'Starting Base ID' and 'Ending Base ID' = enter the workorder ID  
'Posting Date' = the date journals are currently being prepared for
Start

If the above steps do not resolve the issue, review the Work Order/Master Cost Report selecting 'Comparative totals with breakdown' option to check the costs.  If there is a difference between the costs on the work order and the costs posted, run VMFIXWRK on the workorder to correct.

VMFIXWRK is an executable within the VISUAL executable library that recalculates the WORK_ORDER table cost fields.  VMFIXWRK recalculates requirement costs from issues, operation costs from labor tickets, and operation costs for services.  The cost information written to the WORK_ORDER table is summarized from the OPERATION and REQUIREMENT tables. If any changes are made, it will change the posting candidate to Y so the corrected costs flow through.  Run a full costing in order to see the change.

It is recommended VMFIXWRK be run in TEST prior to running in live to review the results, especially the financial impact.

To run VMFIXWRK.EXE:

1.  No users can be logged in
2.  Locate the executable within the VISUAL directory
3.  Double click to log in
4.  Enter a specific work order, eng master, or quote master to recalculate.  Check the bottom 3 check boxes and select 'Go'.


Additional information
When reviewing workorders on the WIP Balance Report with a closed status, verify the close date by going to the Manufacturing Window > Info > Work Order Receipts.  The date of the last receipt will be the close date.  The workorder will remain on the WIP Balance Report until journals have been prepared after the close date.
