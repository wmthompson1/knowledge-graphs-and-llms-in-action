Support does not assist with providing you queries. I can only explain how the tables work. I have explained how WIP_ISSUE_DIST, WIP_ISSUE_DETAIL and INVENTORY_TRANS work.

If you only need to add the part number on the WIP_ISSUE_DIST, you need to query the PART_ID from the INVENTORY_TRANS. Match WIP_ISSUE_DIST and WIP_ISSUE_DETAIL using DIST_NO to get the TRANSACTION_ID. Then match WIP_ISSUE_DETAIL and INVENTORY_TRANS using TRANSACTION_ID to get the PART_ID.

---

In your sample, for WIP_ISSUE_DETAIL, you also need to review DIST_NO = 2. You will then see the changes between dist 2 and 3 only amounts to -74.20. I assume transaction ID 11981 does not have dist 2 and transaction ID 26 has dist 2 with same amount as dist 3.

---

The detail tables are the only table that can show history in VISUAL. The detail records are created when the bottom portion of costing is run (Manufacturing journal preparation). The detail records will hold the value of the transaction when it occurs.  If those cost changes, costing will insert a new record for the same transaction with a new distribution and the new value. The difference between the last two distributions will be what posts to the general ledger.

For example:

Transaction 1 is work order issue for a value of 500.00.  After costing is run the WIP_ISSUE_DETAIL will reflect the transaction id 1 work order id and material value of 500.00. The posting (WIP_ISSUE_DIST) dist 1 would be 500.00.

There is cost change - the value of the inventory transaction record to 550.00. The next time costing is run and the WIP journal is prepared, the WIP_ISSUE_DETAIL will have transaction id 1 twice. Dist. 1 will be for 500.00 and dist. 2 will have 550.00. The posting (WIP_ISSUE_DIST) dist 2 would be 50.00.
