Material Planning Window: Where is Planned Order information stored?

Planned order values displayed in the supply side of the Material Planning Window are stored in the PLANNED_ORDER table. 

ORDER ID - concatenation of the string "PL", the value of the PLANNED_ORDER.PART_ID, a backslash character, and the PLANNED_ORDER.SEQ fields. 
DUE DATE - corresponds to PLANNED_ORDER.WANT_DATE,
RELEASE DATE - calculated by subtracting the part’s lead time from the want date. More information found in KB0739531.
LEAD TIME - typically defined in Part Maintenance; however, if MRP is run by warehouse and the warehouse is independently planned, the lead time is stored in PART.WAREHOUSE. 

The PLANNED_MATL_REQ table also holds planned order information.
