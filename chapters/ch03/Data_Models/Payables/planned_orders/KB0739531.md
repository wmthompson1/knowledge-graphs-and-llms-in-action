KB0739531

How is 'Rls date' determined in Material Planning Window

Article Information
________________________________________________________________________________________________________________


Description : How is Release Date (Rls) determined in Material Planning Window?

Resolution :
The release date is generally equal to the want date less lead time.  The lead time is typically defined in Part Maintenance on the Planning Tab.
Consider these scenarios:

1) Customer Order entered for a fabricated part with a ship date of 11/29/ YYYY and a lead time of 2 (days).  Work order is created by clicking on the New W/O box.  In the Material Planning window:

Date Required = Ship date on Customer Order (11/29/ YYYY)
Due Date = will equal Date Required
Rls Date = will equal order date of the customer order
Suggested Release Date = will equal Due date less lead time = 11/29/ YYYY less 2 days = 11/27/ YYYY.

2) If the work order is manually created in Manufacturing Window (File, New Work Order, from Engineering Master):
Release date: will default in as 2 days less than today’s date (i.e. lead time is used)
Want date: will default in as today’s date (in this case 11/1/ YYYY)

These dates can be changed.
In Material Planning Window:
Due Date = Date work order was created = 11/1/ YYYY
Rls Date = Due Date less lead time = 10/30/ YYYY
Suggested Release date = due date less lead time.

3) If a customer order is entered with a ship date of 11/29/ YYYY, and a link is NOT created to a work order, and there is not enough supply to meet the demand then a Planned Order is suggested by MRP. After running MRP, in Material Planning window:

Due Date = will equal Date Required (from demand) = 11/29/ YYYY
Rls Date = will equal Due Date less 2 day lead time = 11/27/YYYY
Suggested Release date = due date less lead time

4)  Release dates can be affected by Calendar Exceptions.  For example, if a calendar exception is added for a holiday, MRP will not use that day when calculating Release Dates.

 


Note :
Release date is not stored in the database as it is a calculated column.
