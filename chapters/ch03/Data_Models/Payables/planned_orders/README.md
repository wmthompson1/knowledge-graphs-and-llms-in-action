KB3609621

How to view Audit Details of Planned Orders

Article Information
________________________________________________________________________________________________________________


Description :

How to view Audit Details of Planned Orders after including them in Scheduling


Resolution :
To view Audit Details for Planned Orders:

1. Go to Eng/Mfg > Manufacturing Window
2. Pull in any Engineering Master or Work Order
3. Click 'Order Audit' icon
4. Select the 'Schedule ID' of the schedule run that included Planned Orders.
5. Click 'Ok'
6. Planned Orders are located at the bottom of the window and the 'Work Order ID' will begin with 'P'.
7. Highlight the row containing the Planned Order to be reviewed and click 'Show Detail...'.
