# KB1859222

## Document Reference options in Manufacturing Window

### Article Information
________________________________________________________________________________________________________________


**Description : What setting is used to copy Document References from an Engineering Master to a Work Order?
Do the Document Reference options located in Eng/Mfg, Manufacturing Window, Options, Document Reference Options copy document references to a work order from an Engineering Master?
Where are these Document Reference settings stored?


Resolution : The options found under Manufacturing Window, Options, Document Reference Options are:
Copy Document References from Parts
Copy Document References from Resources

These would copy the document references from Part and/or Resources into a Engineering Master, Work Order or Quote Master, not the document references from an Engineering Master. The values are not kept in a table. They are kept in Admin, Preference Maintenance, Section ManufacturingWindow. The Entry would be DocCopyFromPart and DocCopyFromResource.

To copy Documents from an Engineering Master to a work order, the user needs to select the option to do so when generating the work order. For example, if a customer order is entered for the part that is on the Engineering Master and the New Work Order box is checked to create the work order, the program will open a Create New Job window for the user to select a) the status of the work order, and b) whether or not to Copy All Document Reference. If the user does not check this option, any Document References attached to the Engineering Master will not be brought into the work order.

The same thing happens when the user chooses to create a new work order from an Engineering Master in the Manufacturing Window. The user must select the option to Copy Document References in order for them to be brought into the Work Order from the Engineering Master. There is not option to default this to be checked.
