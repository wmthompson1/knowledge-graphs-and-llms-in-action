## KB1475934

## Information about User Defined Fields (Not Customizable)

Article Information
________________________________________________________________________________________________________________


Description : Information about User Defined Fields (Not Customizable)

Resolution :
User Defined Fields (UDF) consists of 2 items:
1) Layout ID (Label set ID)
2) Field Labels

The User Defined Layout IDs and field labels can only be modified in:
- Part Maintenance
- Customer Maintenance
- Vendor Maintenance

The User Defined Fields are populated in each of the following applications and can be unique for each record within each application.

Once the UDF field has been populated in the Parent application, this information can be read in other applications
- Part Maintenance but read only in applications like the Mfg Window, Shop Resource Maintenance
- Customer Maintenance but read only in applications like Customer Order and Shipping
- Vendor Maintenance but read only in applications like PO Entry, PO Req, PO Receipt

The Default Layout ID should only be used for all applications if the information specified on the field labels is generic in nature and can be used by all applications.

Custom Layout IDs can be added so the field labels can then be unique for Parts, Customers Order, and PO's

Changing the Layout ID does not provide additional fields to be entered.
Example: Once a Layout ID is created for Part Info to be entered in Part Maintenance, only the 10 User Defined fields can be used.
Changing to another Layout ID does not change the data entered in those fields.

UDF Layout labels and fields are kept in the UDF_LAYOUT table.

User Defined Field Layout ID  **Default** will always be displayed when user initially accesses User Defined Fields.  Select the correct layout id to be used when adding information to the fields.
