# KB1827640

## Copying Profiles to Users

Article Information
________________________________________________________________________________________________________________


## Description :

In Security Maintenance, what is the difference between using Edit > Copy User/Profile to and Maintain > User Profiles?
How to assign profiles to users.
How to copy profile settings to users.
Using User and Profile settings in Security Maintenance.


## Resolution :
Profiles can be used in two ways.  They can either be assigned to a user(s), or the profile settings can be copied to a user(s).

In Security > Profile/User/Group Security, use Maintain > User Profiles to assign profiles to a user.  A user can be assigned one or many profiles.  When a profile is assigned to a user, the user inherits the profile settings, including macros. The settings are not copied to the user's security record. Therefore, when viewing a user's security record, the system does not display the security settings that the user inherited from the profile. If the profile is changed after it is assigned to a user, the user inherits the changes.

Use Edit > Copy User/Profile to copy profile settings to a user or profile.  This allows the settings of a user or a profile to be initially copied to another user or profile, but then the settings can be changed or tweaked as necessary.  

When multiple profiles are assigned to a user, the system applies security settings cumulatively. For menu security and program security, the most restrictive settings are applied. For example, Profile 1 and Profile 2 are both assigned to a user. Profile 1 denies access to the Inventory menu but grants access to all other menus; Profile 2 denies access to the Engineering menu but grants access to all other menus. The user would not have access to either the Inventory menu or the Engineering menu.

If a second profile is copied to the same user, the second profile overwrites the settings of the first profile. If the profile is changed after being copied to the user, the user does not inherit the new
profile settings. If the profile contains macros, the macros are not copied to the individual user.
