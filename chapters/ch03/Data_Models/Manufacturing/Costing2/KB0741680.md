Description :

Information about the Costing Utilities log files


Resolution :
Every time Costing Utilities runs, a log file is generated - VMAPLUTLSITEID.LOG.  This log file contains start and end times for each process and identify certain errors.  The log file should be reviewed after each costing run.

There is also a DEBUG log that can be turned on.  Use this if VMAPLUTLSITEID.LOG does not show any details.

To turn this on:

Add the setting to Admin > Preferences Maintenance:
Section:  CostingUtilities
Entry:  Debug
Value:  Y

This writes to the VMAPLUTL.DBG

For Projects:
ProjectCostDebug=Y
This writes to VMPRJCST.LOG

Typically VMAPLUTL.dbg will be in the directory where the executables are stored, use notepad to open the file.

The debug log only works for the top two options of Costing Utilities.

The Costing Log writes to two places:

The location of the VISUAL executables.  To determine that location:  Right click on the VISUAL icon.  Go to Properties > Open File Location.  If the users Target and Start in paths differ, the log may be written to both places.
The user's local configuration file directory.  Normally that location is specified by the Local Directory registry key found under: HKEY_CURRENT_USER\Software\Infor Global Solutions\VISUAL Manufacturing\Configuration
The following steps can help determine the local directory path:

Locate the VISUAL.INI, VMBROWSE.INI or VFBROWSE.INI file on the computer.
Go to START | Run, type in REGEDIT, OK
Drill down to HKEY_CURRENT_USER\Software\Infor Global Solutions\VISUAL Manufacturing\Configuration, then click on Configuration folder.
If the Local Directory= setting is found in the Configuration folder, make sure it refers to the directory found in step #1. If not, change the value to this directory.
If the Local Directory= setting is not found in the Configuration folder, it can be added manually though the preferred method would be to perform an 'icons only' install while logged in as the user.
If the registry entry is added manually, choose Edit | New String Value, then type over New Value #1 with Local Directory, press Enter to save. Press Enter again to bring up the edit dialog where the user can enter a Value for the Local Directory=. This value should be the directory found in step #1.
