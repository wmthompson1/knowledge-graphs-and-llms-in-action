Infor Writes:

An issue return should derive its value from the last issue(s) to the workorder.
Every time Costing is run, an I/I that has 0 value is reviewed.
If you have already run the top two options in Costing Utilities but these issue return transactions are still valued at $0, please perform the following in a TEST copy first to verify results before applying in live.

Part ID 20248E-410380-MIL dated 7/1/2026
Part ID 70756B-063-MIL-NG-AMS dated 12/1/2025
Part ID 70756B-071 106 X 37 dated 11/1/2025
Part ID MS20253P2-7200L dated 7/1/2026
Part ID 70750C-050 dated 3/1/2026

First, run Recalculate Distributions.
Admin > Costing Tools > Options > Recalculate Distributions
Enter appropriate date
Enter part ID in the Starting and Ending fields
Recalculate Distributions box is selected by default
Select Start
Check if the cost of the issue return has been corrected.

If running Recalculate Distributions does not work, run Force FIFO.
Admin > Costing Tools > Options > Recalculate Distributions
Enter appropriate date
Enter part ID in the Starting and Ending fields
Select Force FIFO Re-evaluation box
Select Start
Check if the cost of the issue return has been corrected.

If the Recalculate Distributions and/or the Force FIFO do not work, run a few more scripts.
