The Costing Log writes to two places:

The location of the VISUAL executables.  To determine that location:  Right click on the VISUAL icon.  
  Go to Properties > Open File Location.  If the users Target and Start in paths differ, the log may be  
   written to both places.
The user's local configuration file directory.  Normally that location is specified by the Local Directory registry key found under: HKEY_CURRENT_USER\Software\Infor Global Solutions\VISUAL Manufacturing\Configuration

## Steps

The following steps can help determine the local directory path:

1. Locate the VISUAL.INI, VMBROWSE.INI or VFBROWSE.INI file on the computer.
Go to START | Run, type in REGEDIT, OK
Drill down to HKEY_CURRENT_USER\Software\Infor Global Solutions\VISUAL Manufacturing\Configuration, then click on Configuration folder.
If the Local Directory= setting is found in the Configuration folder, make sure it refers to the directory found in step #1. If not, change the value to this directory.
If the Local Directory= setting is not found in the Configuration folder, it can be added manually though the preferred method would be to perform an 'icons only' install while logged in as the user.
