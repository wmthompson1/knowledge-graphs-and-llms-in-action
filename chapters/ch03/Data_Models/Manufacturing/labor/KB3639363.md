## Elapsed Hours are incorrect when using 'Prorate by Hours' in Wedge Barcode

Article Information
________________________________________________________________________________________________________________


Description :

Elapsed Hours are incorrect when using 'Prorate by Hours' in Wedge Barcode

Recreated in:
Bar Code Labor Ticket Entry
VMBCLABR.exe, Versions 10.0.0.022 SP15 and 11.0.0.010 SP3


**Steps to Reproduce :**

1. Eng/Mfg > Manufacturing Window
    Find or add 3 released work orders
    Make note of Operation Sequence No's

2. Launch Wedge Barcode
    User ID: SYSADM
    File > Administrator Setup
    Under Multiple Jobs, select 'Prorate Hours spent on work'
    'Ok'
    Enter Employee ID
    <Tab>
    'Clock In'
    'Yes' to "Confirm transaction"
    Enter Employee ID
    <Tab>
    'Start Run'
    <Enter>
    Enter 'Work Order Base ID','Lot ID','Split ID','Sub ID','Operation Seq#' of operation.
    'Yes' to "Confirm transaction"
    Enter Employee ID
    'Start Run'
    <Enter>
    Enter 'Work Order Base ID','Lot ID','Split ID','Sub ID','Operation Seq#' of operation.
    'Yes' to "Confirm transaction"
    Enter Employee ID
    <Tab>
    'Start Run'
    <Enter>
    Enter 'Work Order Base ID','Lot ID','Split ID','Sub ID','Operation Seq#' of operation.
    'Yes' to "Confirm transaction"

3. Wait 15 minutes
     Enter Employee ID
     <Tab>
     'Stop Job'
     Select one of the 2 work orders
     <Tab> through the fields
     'Yes' to "Confirm transaction"
     Enter Employee ID
     <Tab>
     'Stop Job'
     <Tab> through the fields
     'Yes' to "Confirm transaction"

4. Enter Employee ID
     <Tab>
     Select 'Clock Out'

5. Eng/Mfg > Labor Ticket Entry
     Review labor tickets created.
     Hours worked should be the same for all 3 tickets - they are not.
     Example:  3 labor tickets for 15 minutes should be 5 minutes per ticket. 


Work Around :
Labor Ticket Entry
Select 'Employee ID' and 'Transaction Date'
Edit > Recalc Proration


Resolution :
This defect has been resolved in VISUAL 10 SP17 and 11.1 SP1.

To download: 
1.  From Infor Concierge, select 'Products and Subscriptions', then select 'Visit Infor Product Download Center'
2.  From the 'Product List' select 'Infor', then select 'Enterprise Resource Planning'
3.  From 'Enterprise Resource Planning', select 'VISUAL'
​4. Select 'Infor VISUAL ERP'
