# KB2202604

## Wedge Barcode creating transactions for 0.01 hours

Article Information
________________________________________________________________________________________________________________


Description :

Barcode Labor Ticket Entry is creating transactions that round up to 0.01 hours. When doing the same amount of time in Labor ticket entry, it round up to 0.00 hours.

 


Resolution :
By design, Bar Code will create labor tickets with a small amount of time.  If this is not desired, use Labor Ticket Entry to enter Elapsed Hours of 0.
